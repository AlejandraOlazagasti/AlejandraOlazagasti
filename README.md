## La historia corta

Estudié comunicología porque me obsesiona cómo las personas **reciben** información.
Después descubrí que el código es el medio más honesto que existe: o funciona, o no funciona.

Llevo **5 años** construyendo interfaces y servicios que hacen que los dos mundos
se entiendan. Trabajo como developer en **TV Azteca** y co-fundé **PineAipple**,
una fábrica de software donde mi sello personal es el scrollytelling — animaciones
que no decoran, sino que *narran*.

Antes de eso estuve en **Academlo**, donde además de desarrollar fui imagen del canal
de YouTube. Aprendí que explicar bien algo difícil es una habilidad tan técnica
como escribirlo.

## Proyecto destacado — PineAipple Web

<a href="https://pineaipple.com">
  <img align="right" src="https://img.shields.io/badge/→_pineaipple.com-F5A200?style=flat-square" alt="pineaipple.com"/>
</a>

El sitio web de la fábrica de software que co-fundé. Lo que parece magia es código:

- **Three.js + WebGL** — mascota 3D que se arma en tiempo real mientras carga la página
- **Scrollytelling** — cada sección se "activa" narrativamente conforme el usuario avanza
- **Astro** como framework, Cloudflare como infraestructura
- **Patrón de circuito generativo** programado en Python + Blender, exportado a GLSL

Es el tipo de trabajo que más disfruto: donde el diseño y la ingeniería no se pueden separar.
